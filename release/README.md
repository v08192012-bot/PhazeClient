# PhazeClient — MSDF fix (шрифты и текстуры)

`PhazeClient-msdf-fix-1.21.4.jar` — jar-ресурспак для Minecraft **1.21.4** (`pack_format` 46),
который подменяет внутри мода один файл:

```
assets/phaze/shaders/core/msdf_font.fsh
```

## Что чинит

MSDF-шейдер считал экранный диапазон distance field как

```glsl
float pixels = max(Range * inversesqrt(h.x * h.x + h.y * h.y), 1.0);   // было
```

где `h = vec2(dFdx(u), dFdy(v)) * atlasSize`. Для неповёрнутого квада `dFdx(u) == dFdy(v)`,
поэтому `|h|` оказывается в `sqrt(2)` больше истинной скорости изменения координаты —
`pixels` занижается в `sqrt(2)` раз, и `smoothstep(-S, S, dist * pixels)` размазывает край
глифа/иконки примерно в 1.4 раза шире нормы:
замеры на реальных атласах — **+25 %** на тексте size 8 и **+41 %** на иконках size 21.
Это и есть «как будто включено сглаживание».

На повёрнутых квадах хуже: `dFdx(u)` и `dFdy(v)` одновременно стремятся к нулю
(при 90° строго равны нулю) → `inversesqrt(0) = +Inf` → сглаживание исчезает полностью,
края становятся «лестницей» и дрожат при движении. Поворот используется в
`BackgroundComponent` (крестик на 45°) и в `Image.render()` (любой `rotation`).

Стало — каноническая формула, та же, что уже используется в `phaze:loading/msdf`:

```glsl
vec2 unitRange     = vec2(Range) / vec2(textureSize(Sampler0, 0));
vec2 screenTexSize = vec2(1.0) / max(fwidth(TexCoord), vec2(1.0e-6));
float pixels = max(0.5 * dot(unitRange, screenTexSize), 1.0);           // стало
```

Нижняя граница в один экранный пиксель сохранена — иначе пустая часть мелких
MSDF-квадов становится полупрозрачной и за иконками проступает бледный квадрат.

## Установка

1. Положить `PhazeClient-msdf-fix-1.21.4.jar` в `.minecraft/resourcepacks/`.
2. В игре: Настройки → Пакеты ресурсов — включить его и **поднять выше**
   «Mod Resources» / «Fabric Mods» (по умолчанию новый пакет встаёт вверх — так и надо).
3. Готово, перезаходить не нужно (F3+T перезагрузит шейдеры).

## Почему это ресурсопак, а не пересобранный мод

В репозитории лежат только декомпилированные исходники (JD-Core) без `build.gradle`,
поэтому бинарную сборку мода здесь сделать нечем. Сам фикс в исходниках — коммит в этой
ветке, файл `assets/phaze/shaders/core/msdf_font.fsh`; при следующей обычной сборке
мода ресурсопак больше не нужен.
